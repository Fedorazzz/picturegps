# PictureGPS v1.0

**PictureGPS** — это легкий и быстрый браузерный инструмент для наложения информационных штампов на фотографии. Он идеально подходит для полевых выездов, осмотров объектов и документирования местоположения.

## 🚀 Основные возможности

*   **Живое превью**: Любые изменения текста или стиля мгновенно отображаются на холсте.
*   **Автоматизация данных**:
    *   Поиск адреса и координат через API OpenStreetMap (Nominatim).
    *   Автоматическое заполнение текущей даты и времени при запуске.
*   **Гибкий дизайн штампа**:
    *   Управление **размером** шрифта (в % от высоты фото для сохранения пропорций).
    *   Настройка **веса (жирности)** шрифта и **толщины обводки** для идеальной читаемости на любом фоне.
    *   Выбор любого цвета через удобную палитру.
*   **Умное именование файлов**: Автоматическая генерация имени при скачивании по шаблону `ДДММГГЧЧММ_ТранслитУлицы.jpg`.
*   **Адаптивный интерфейс**: 
    *   **Desktop-режим**: Двухпанельный интерфейс (настройки слева, превью справа) для больших мониторов.
    *   **Mobile-режим**: Компактная вертикальная верстка для работы «в полях» прямо со смартфона.
*   **Темная тема**: Современный интерфейс с комфортной палитрой Deep Night, снижающей нагрузку на глаза.

## 🛠 Технический стек

*   **HTML5 / CSS3**: Современная верстка на Flexbox и Grid.
*   **JavaScript (Vanilla)**: Работа с Canvas API для отрисовки графики без тяжелых библиотек.
*   **Nominatim API**: Геокодирование адресов в реальном времени.
*   **Blob & URL API**: Надежная генерация и скачивание файлов высокого разрешения.

## 📋 Инструкция по использованию

1.  Открой файл `PictureGPS.html` в любом современном браузере.
2.  Выбери фотографию через кнопку **«Выберите фотографию»**.
3.  Введи адрес объекта в поле поиска и нажми **«Найти данные»** — координаты и адрес заполнятся автоматически.
4.  Настрой внешний вид штампа (размер, толщину обводки, жирность) с помощью ползунков.
5.  Нажми **«Скачать готовое фото»**.

## 📝 Формат штампа

Данные накладываются в правом нижнем углу в строгом порядке:
1.  **Дата и время** (например: *4 мая 2026 время: 23:15*).
2.  **Адрес** (№ дома и название улицы/проезда).
3.  **Координаты** (Широта, Долгота).
4.  **Дополнительный текст** (Административный округ и город).

## 🔒 Конфиденциальность

Приложение работает полностью локально в вашем браузере. Ваши фотографии **не отправляются** на сервер. Запросы к API Nominatim используются исключительно для преобразования текстового адреса в координаты.
